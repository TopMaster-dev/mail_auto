# 反響メール自動化システム 運用マニュアル

レントマガジン株式会社 ご担当者さま向けの操作・運用マニュアルです。

---

## 1. システムの概要

お客様からの反響メールを自動で受信し、

1. NGワード・差別的表現を自動チェック
2. 物件情報を自動照合（空室判定）
3. AIが返信文案を自動生成
4. スプレッドシート／管理画面に記録

します。**初期設定では自動送信せず**、ご担当者が内容を確認してから送信します
（誤送信防止）。返信後は、お客様が返信されるまで **2通目・3通目の追客メールを
自動送信** します。

---

## 2. 日々の運用フロー

```
お客様がメール送信
      ↓（自動）
受信・チェック・文案生成 → ステータス「自動送信可」
      ↓（ご担当者）
管理画面で内容を確認・編集 →「この内容で送信」
      ↓（自動）
2日後に2通目、さらに3日後に3通目を自動送信
      ↓
お客様が返信 → 追客は自動停止
```

ご担当者の作業は基本的に **「管理画面で確認して送信する」** だけです。

---

## 3. 管理画面の使い方

### ログイン
- URL：（デプロイ時に設定したアドレス）
- パスワード：ご担当者にお渡しした管理用パスワード

### 一覧画面
- 新着の問い合わせが上から表示されます。
- 上部のボタンでステータス別に絞り込めます。
- 「確認」ボタンで詳細画面へ。

### 詳細画面
- 左：お問い合わせ情報（顧客・物件・空室有無・NGワード等）
- 右：**返信文案（編集可能）**
  - **件名**・**本文**をその場で編集できます。
  - **下書き保存**：編集内容を保存（送信はしません）。
  - **この内容で送信**：表示中の内容でお客様へメール送信します。
- 「追客を停止する」：このお客様への追客メールを止めます。

---

## 4. ステータスの意味

| ステータス | 意味 | 対応 |
|------------|------|------|
| 自動送信可 | 文案生成完了・送信待ち | 内容確認のうえ送信 |
| AI返信文生成済み | 文案生成完了 | 内容確認のうえ送信 |
| 要確認 | AI処理で確認が必要 | 内容を確認し手動対応 |
| NG検出 | NGワード／差別表現を検出 | 内容を確認し慎重に対応 |
| 送信済み | 返信メール送信済み | 追客は自動進行 |
| 返信あり | お客様から返信あり | 追客は自動停止済み |

---

## 5. スプレッドシートでの管理

| シート | 用途 |
|--------|------|
| 問い合わせ一覧 | すべての問い合わせと文案・ステータス |
| NGワード | 検出するNGワード（**ワード／カテゴリ**列に追記可能**） |
| 設定 | 自動送信などの動作設定 |
| 送信履歴 | 送信したメールの記録 |
| 追客履歴 | 自動追客の送信記録 |
| 要確認履歴 | NG検出・エラーの記録 |

- **NGワードの追加・削除**：「NGワード」シートに行を追加・編集するだけで、
  次回以降のチェックに自動反映されます。

---

## 6. 自動送信を有効にする場合（上級・要注意）

初期設定では **すべて確認後送信** です。完全自動送信に切り替えるには、
開発側で `settings.yaml` の `send.all_require_confirmation: false` に変更し、
「設定」シートの条件を有効化します。**十分な試験運用の後にのみ** 切り替えて
ください。

---

## 7. よくある質問

**Q. 通知メール（ポータル・事務局など）も処理されますか？**
A. 自動でフィルタされ、お客様の問い合わせのみ処理します。

**Q. 文案を修正して送りたい**
A. 詳細画面の本文を直接編集して「この内容で送信」してください。

**Q. このお客様には追客したくない**
A. 詳細画面の「追客を停止する」を押してください。

**Q. メールが自動で送られてしまった**
A. 初期設定では自動送信されません。設定変更後のみ自動送信されます。
